# GEPREK MANTAP

## Deskripsi Proyek

Geprek Mantap merupakan website sederhana yang dibuat untuk memberikan informasi mengenai daftar menu dan harga makanan serta menyediakan formulir pemesanan secara online.

## Tujuan

Membuat website menggunakan HTML5 dan CSS dengan menerapkan tabel, formulir, validasi input, serta pengelolaan proyek menggunakan Git dan GitHub.

## Fitur Website

1. Halaman beranda.
2. Daftar menu dan harga makanan.
3. Formulir pemesanan.
4. Pilihan level pedas.
5. Informasi kontak.

## Teknologi yang Digunakan

* HTML5
* CSS3
* Git
* GitHub
